Bibliothèque de composants

Cette page interne montre un exemple réel de chaque composant disponible dans le système de sections réutilisables, avec le vrai CSS du thème — pas une maquette. Chaque page du site (Accueil, La Sophrologie, Infos pratiques…) se construit en empilant ces mêmes composants via "+ Ajouter une section" dans Réglages du thème.

Chaque composant a une "mise en page" (le type de bloc) et quelques champs à remplir selon ce type. Les champs "Cartes" et "Chiffres clés" utilisent un format texte simple : une ligne par élément, avec :: pour séparer un nom d'une description quand les deux existent.

Composant Texte simple

Le plus simple des composants : un titre optionnel et un bloc de texte riche (formaté depuis l'éditeur Publii — gras, listes, liens…). Champs : label (optionnel), titre (optionnel), texte.

Exemple Un titre de section

Voici à quoi ressemble le composant Texte simple avec un titre et un paragraphe de texte formaté. On peut y mettre du texte en italique, des liens, des listes, etc. — tout ce que l'éditeur riche de Publii permet.

Composant 2 colonnes

Deux textes côte à côte, un texte + une liste à puces si le champ éléments de liste est rempli, ou un texte + une photo si le champ image est rempli. Champs : label, titre, texte, texte 2 (ignoré si des éléments de liste ou une image sont fournis), éléments de liste, image.

Deux textes côte à côte

Colonne de gauche : par exemple une explication ou une liste d'avantages.

Colonne de droite : un complément, un témoignage, ou toute autre information liée.

Variante Texte + liste à puces

Même composant, mais avec une liste à puces en colonne 2 au lieu d'un second texte — pratique pour un paragraphe explicatif suivi d'une liste de points concrets.

Composant Cartes

Une grille de cartes, chacune avec un nom et une description optionnelle. Champs : label, titre, éléments (une ligne par carte, format Nom :: Description).

Composant Encadré (callout)

Un bloc de texte mis en valeur visuellement (sans titre ni label) — ou, si un titre est renseigné, un encadré bordé "à retenir" avec label, titre, une ligne clé et un paragraphe de clôture optionnel après un séparateur. Champs : label, titre, texte, texte 2 (paragraphe de clôture, uniquement avec titre).

Ceci est un encadré. Idéal pour une information importante que l'on veut faire ressortir du reste du contenu.

À retenir

Un encadré bordé avec titre

Une information clé mise en avant.

Un paragraphe de clôture, après un séparateur — utile pour un encadré plus riche qu'une simple ligne.

Composant Étapes numérotées

Une liste verticale d'étapes numérotées (1, 2, 3…) — le numéro est calculé automatiquement, pas besoin de le taper. Champs : label, titre, éléments (format Titre de l'étape :: Description).

Composant Publications

Pas de champs propres non plus, mais différent de Services/Cabinets : au lieu de lire un champ Réglages du thème, ce composant interroge en direct vos vrais articles Publii étiquetés publications et affiche les 6 derniers, à jour, sans jamais retoucher les Réglages du thème. Étiquetez un article publications (+ une étiquette secondaire pour la mention en majuscules) dans Publii → Articles pour qu'il apparaisse ici. Voir le README du composant.

Composant Conférences

Même mécanisme que Publications/Actualités, mais avec un style volontairement différent : un bloc plus grand par article (date, titre, extrait, lien « Lire la suite ») plutôt qu'une liste compacte ou une grille — deux façons d'afficher des articles, au choix. Étiquetez un article conferences dans Publii → Articles pour qu'il apparaisse ici ; le programme complet de la conférence s'écrit dans le corps de l'article lui-même, pas dans ce composant.

Composant Identité

Logo (ou nom du site) + sous-titre optionnel + description — utilisé pour la colonne « identité » du pied de page et le logo de l'en-tête, avec un style différent selon l'endroit. Champs : style (navigation/pied de page), affichage (logo/logo+texte/texte — un nom de site est lui-même une forme de logo), sous-titre, description, encadré sombre autonome (à activer hors pied de page — son texte clair n'est lisible que sur fond sombre, voir ci-dessous).
